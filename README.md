# Future Lab

A portfolio of 20 enterprise-AI product concepts spanning observability, security, banking, payments and retail. The homepage includes a working synthetic incident simulator, **Sentinel 360**.

## Publish with GitHub Pages (no build tools required)
1. Create a **public** GitHub repository named `future-lab`.
2. Upload `index.html` and `README.md` to the repository root (GitHub: **Add file → Upload files**).
3. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**; choose `main` and `/ (root)`; Save.
4. Open `https://YOUR_USERNAME.github.io/future-lab/` when deployment completes.

No backend, tokens, secrets, AI API fees, npm, or Codespaces are needed for this initial version.

## Scope and truthfulness
All telemetry and financial scenarios are synthetic. The observability simulator is rule-based, not powered by a language model. Other product cards are roadmap concepts, not working products.
